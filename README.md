# Global Movie Analytics Dashboard
# Overview
This project analyzes movie industry data to uncover trends in revenue, ratings, and genres using Power BI.

# Objectives
- Analyze top-performing genres
- Study revenue vs ratings relationship
- Identify trends over time

# Tools Used
- Power BI
- Excel / Dataset

# Key Insights
- Action and Drama genres generate highest revenue
- Higher ratings often correlate with higher revenue
- Recent years show increasing movie production
